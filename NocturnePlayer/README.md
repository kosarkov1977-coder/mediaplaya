# Nocturne Player

Android-плеер на Kotlin и AndroidX Media3, Android 10+ (minSdk 29). MVVM, Room, DataStore, Navigation, Material 3. Исходники лежат в этом проекте; вручную вставлять фрагменты кода не нужно.

## Открытие и сборка

1. Распакуйте весь архив в каталог с коротким путём, например C:/Android/NocturnePlayer.
2. Откройте этот каталог через Android Studio → Open. Используйте актуальный стабильный Android Studio с поддержкой AGP 9.5.1.
3. В SDK Manager установите Android SDK Platform 37.0 и Build Tools 36.0.0. Минимальный Android устройства — 10, API 29.
4. Выберите встроенный JDK Android Studio (JDK 17 или новее; проект проверяется на JDK 25). Дождитесь Gradle Sync. Нужен интернет к Google Maven, Maven Central и Gradle Plugin Portal.
5. Выберите устройство и нажмите Run. Либо запустите в PowerShell: .\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
6. APK появится в app/build/outputs/apk/debug/app-debug.apk. Готовый APK подписан тестовым ключом этой сборки. Если после его установки локальная сборка сообщает INSTALL_FAILED_UPDATE_INCOMPATIBLE, удалите готовый APK с устройства перед установкой своей сборки (история приложения при удалении сбрасывается). Установка через Android Studio или adb install -r app/build/outputs/apk/debug/app-debug.apk.

Gradle Wrapper включён в проект. Для Linux/macOS перед сборкой выполните chmod +x gradlew и используйте ./gradlew вместо gradlew.bat.

Не создавайте новый Empty Activity поверх этих файлов. local.properties содержит локальный путь SDK и не включается в архив: Android Studio создаёт его для вашего компьютера.

## Использование

В видеотеке разрешите чтение видео либо нажмите + → Открыть видео / Добавить папку. На Android 14+ можно разрешить доступ только к выбранным видео. USB-накопитель выбирается через системный SAF, если Android предоставляет его в файловом менеджере.

Добавленная папка сканируется рекурсивно. Чтобы автоматически находить соседние субтитры, предоставьте доступ к родительской папке видео. Одно разрешение на отдельное видео не даёт доступ ко всем соседям. Подходят Movie.mkv + Movie.srt, Movie.ru.ass или Movie_en.vtt. Произвольные имена подключаются вручную.

На экране плеера: Субтитры → Добавить файлы. Можно выбрать несколько файлов; активен один внешний файл. Остальные остаются в меню. Там же доступны встроенные дорожки, отключение, оформление, кодировка и задержка ±0,1 с. Положительная задержка показывает текст позже. Смена файла и задержки не перезапускает видео.

Включённое «Сохранять оформление файла» оставляет поддерживаемые Media3 стили и позиционирование. Выключите его для своего размера, цвета, шрифта и отступа. Доступны системные семейства шрифтов. Прозрачность фона задаётся отдельно. Настройки, выбранный внешний файл и задержка сохраняются отдельно для URI каждого видео; общие настройки применяются к новым видео.

Жесты: двойное касание по сторонам ±10 секунд; горизонтальное движение — перемотка до 120 секунд на ширину экрана; слева вверх/вниз — яркость окна, справа — системная громкость; два пальца — масштаб 0,5–3×. Касание свободного участка показывает/скрывает панель. Кнопки и шкала времени принимают обычные касания. Блокировка оставляет только кнопку разблокировки. Жесты отключаются в настройках.

Кнопки «Пред.» и «След.» следуют текущему списку видеотеки/плейлиста. Автопереход управляется настройкой. Позиция сохраняется каждые 3 секунды и при уходе с экрана. Вне PiP воспроизведение при сворачивании приостанавливается.

Через + создаются плейлисты и виртуальные папки. Меню ⋮ у видео позволяет добавлять его в коллекцию, удалять связь и перемещать в начало. Виртуальные папки группируют ссылки внутри приложения и не перемещают оригиналы на диске. Физические папки и USB подключаются через SAF.

## Границы совместимости

* Расширения MP4, MKV, AVI, MOV, WebM, TS, M4V, FLV распознаются. Реальная совместимость зависит от контейнера, профиля кодека и декодеров устройства. Включён fallback на другой доступный декодер. FFmpeg/libVLC и программные декодеры не поставляются. Нельзя обещать воспроизведение любого AVI, DTS или Dolby-профиля на любом телефоне.
* ASS/SSA разбираются штатным парсером Media3: сохраняются те стили, цветовые spans и позиции, которые он поддерживает. Это не libass: сложные karaoke, векторная графика, анимации, трансформации и вложенные шрифты Matroska могут отличаться или не поддерживаться. Субтитры не конвертируются в плоский SRT.
* Задержка применяется к внешним субтитрам. Встроенные субтитры отображаются штатным Media3 UI без изменения тайминга.
* Автоопределение кодировки: BOM UTF-16, корректный UTF-8, затем Windows-1251; для других файлов выберите кодировку вручную. Лимит внешнего файла — 16 МБ.
* SAF-разрешение сохраняется между запусками. При извлечении USB, удалении или перемещении файла ссылка может стать недоступной; выберите файл/папку заново. MediaStore и SAF иногда представляют один файл разными URI — они могут появиться двумя записями.
* Приложение не сканирует закрытые каталоги Android/data и не запрашивает полный доступ ко всем файлам. Облачные SAF-провайдеры зависят от доступности провайдера.
* Это исходный проект и debug-сборка. Для публикации задайте собственные signingConfig, идентификатор и проведите испытания на целевых устройствах.

## Архитектура

NocturneApp предоставляет репозитории. data/ отвечает за Room, сканирование, SAF и парсинг субтитров. LibraryViewModel управляет запросом, сортировкой и фильтрами. PlayerViewModel владеет ExoPlayer, MediaSession и состоянием воспроизведения. ui/ отображает состояние и системные диалоги. player/ содержит таймлайн субтитров и обработку жестов. MainActivity размещает NavHost, логика плеера находится отдельно.

Точное дерево файлов — FILE_TREE.txt. Файлы Kotlin находятся в app/src/main/java/dev/nocturne/player, XML — в app/src/main/res, манифест — app/src/main/AndroidManifest.xml. Все пути в дереве заданы относительно корня проекта.
